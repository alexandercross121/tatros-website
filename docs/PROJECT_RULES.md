# Tatros Engineering Rules

## Philosophy

Simple.
Clear.
Purposeful.

## UX

- One message per section.
- One primary CTA.
- Less is more.
- Design for scanning.

## Engineering

- Reuse components.
- Reuse tokens.
- Semantic HTML.
- Accessible by default.
- Mobile-first.
- No duplicate CSS.

## Content

- Plain English.
- Maximum 7-word headings.
- Maximum 2 short sentences.
- Never invent facts.

## Quality

- WCAG 2.2 AA
- Lighthouse 95+
- Responsive
- Production-ready
